# Каталог загрузок APK для сайта Lorit AI

Сюда помещается готовый скомпилированный файл `Lorit-AI.apk`.
При нажатии кнопки «Скачать APK» на сайте `web/index.html` скачивается данный файл:

* Имя файла: `Lorit-AI.apk`
* Ссылка на сайте: `./downloads/Lorit-AI.apk`
* Собрать релизный или дебаг APK можно командой:
  ```powershell
  .\gradlew.bat assembleDebug
  ```
  После чего скопировать файл `app/build/outputs/apk/debug/app-debug.apk` в эту папку под именем `Lorit-AI.apk`.
